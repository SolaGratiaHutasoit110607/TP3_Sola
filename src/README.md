# Character Manager — TP3 (Java Visual SIH-6406)

Character Manager adalah aplikasi Java berbasis console yang menjadi fondasi model data untuk game RPG sederhana. Class `Character` menerapkan prinsip encapsulation (atribut private, akses lewat getter/setter dengan validasi), dan `CharacterType` berupa enum agar jenis karakter selalu valid. `Main` mendemonstrasikan pembuatan karakter, kenaikan level dengan penghitungan ulang HP dan attack, atribut `mana`, serta pengecekan `isAlive()`.
